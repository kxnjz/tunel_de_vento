# tunel_de_vento
Desenvolvimento de um túnel de vento experimental para medição de forças aerodinâmicas sobre objetos, utilizando ESP32, ventoinha, estrutura em MDF e componentes fabricados por impressão 3D. Projeto desenvolvido no âmbito da bolsa de monitoria, com foco em experimentação, instrumentação e aplicação prática de tecnologias do laboratório Maker.
